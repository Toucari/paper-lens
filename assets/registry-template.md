# Registry — 全量索引

> **唯一作用**：让"往回看"这件事有外部清单托底，不依赖记忆。
> 每读完一篇**立即登记**，不要攒到最后一批再补——补的时候一定会漏。

## 字段说明

| 列 | 含义 |
|---|---|
| round | 轮次编号，与 `rounds/` 下的导航文件对应 |
| # | 轮内顺序 |
| short | 论文短名，全库唯一 |
| venue year | 场子 + 年份 |
| summary file | 单篇总结的相对路径 |
| grade | §八 的档位（A/B/C） |
| score | 五维加权总分，保留两位 |
| sections ok | 八节是否齐全：✅ / ❌ 缺哪节 |
| last check | 最近一次"历史更新判断"的日期 |

## 维护规则

- **只有 `last check` 列允许自动更新。** 其余列随单篇文件更新，改动前要征得同意。
- 评级权威 = 各单篇文件的 §八。本表只登记，不定义。
- 短名发生冲突时，用 `会议缩写-短名` 区分。
